## Sitewide Issues (Affecting All Pages)

### Issue 1: Unused JavaScript (~233 KiB on every page)
- Present on: All 17 pages
- Estimated savings: 70-260ms TBT reduction depending on page
- Root cause: GTM, Google Analytics, ClickCease, Trustindex scripts load unconditionally
- Fix: Defer third-party scripts, load after user interaction, or use partytown

### Issue 2: LCP driven by product/collection images
- Present on: All product pages (6), all collection pages (6), some blogs
- Root cause: Product images served from Cloudflare KV/R2 are not optimally sized or formatted
  for mobile viewports. Images are likely 1000x1000px served to 340px-wide containers.
- Fix: Serve WebP with responsive srcset, preload the LCP image, use correct size attribute

### Issue 3: SEO capped at 92 across all pages
- All 17 URLs score exactly 92 for SEO. This is consistent with the 2026-03-05 audit finding
  about Cloudflare-injected Content-Signal directives in robots.txt failing Lighthouse validation.
- Fix: Either suppress the Cloudflare injection or add explicit allow rules
